# Advanced Radar Network

Advanced Radar Network splits vanilla radar's local-visibility and long-range-scanning jobs into two separate tiered progressions: observation radars for local always-on visibility, and reconnaissance radars for long-distance sector scanning.

This is an early 0.1.x release graduated out of Jason's tweak-heap incubation mod. The mod loads and the tiered progression is implemented, but balance values and broad compatibility with other radar/visibility mods should still be treated as experimental.
